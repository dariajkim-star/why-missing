## 1. 형식 검수 (F1~F5) — **통과해도 무효일 수 있다**

기존에 지켜 온 다섯 요건이다. 새로 만든 것이 아니다.

- [ ] **F1 사전 고정** — 임계가 측정보다 **먼저** 커밋됐는가 (커밋 해시로 확인)
- [ ] **F2 임계 명시** — 합격선이 숫자로 적혀 있는가 (*"충분히"*·*"대체로"* 금지)
- [ ] **F3 반올림 금지** — 근소 미달을 통과로 올리지 않겠다고 적혀 있는가
- [ ] **F4 사후 조정 금지** — 결과를 보고 임계를 고치지 않겠다고 적혀 있는가 (계약 8)
- [ ] **F5 기각 방향** — **무엇이 관측되면 죽는지**가 적혀 있는가 (살리는 조건만 적힌 사전등록은 사전등록이 아니다)

> 🔴 **F1~F5를 전부 통과하고도 무효였던 실례가 있다** — John 원안 3/5(M4).
> **형식 검수만으로 충분하다는 가정이 그 사건의 원인이었다.** 그래서 §2가 있다.

## 2. 실질 검수 (C1~C6) — **M1~M6에서 온 것**

각 항목은 **질문 · 미충족 시 처분 · 출처 사건**으로 되어 있다.
출처 사건은 전부 **실제로 우리가 지불한 값**이다.

### 🔴 C1. 판독자 노출 — **가장 무겁다**

- [ ] **홀드아웃·블라인드 판독이 있는가?** 있다면 아래를 전부 확인한다.
- [ ] **판독자가 외부인인가.** 「가능하면」이 아니라 **「반드시」**다
- [ ] **개봉 전 판독자에게 기계 출력을 어떤 형태로도 언급하지 않았는가** —
      **요약·경향·*"큰 회사에서는 ①이 1순위가 아니었다"*까지 전부 노출이다**
- [ ] 노출이 발생했다면 **그 건을 청정 칸에서 제외**하고, 제외 사실을 결과 문서에 적었는가

| | |
|---|---|
| **미충족 시** | 그 홀드아웃은 **등급 회복 수단이 아니다.** 개봉은 유효하되 **청정 신호 0**으로 기록한다 |
| **출처** | **M1** — 홀드아웃 5곳 개봉에서 **청정 칸 0개**. 원인은 n=5가 아니라 **브리핑 노출**(그럼발 자인). post-hoc² 할인을 벗을 **단 한 번의 카드**를 절차로 태웠다 |
| **왜 1위인가** | M2·M3는 등급을 **낮췄고**, M1은 **그 등급을 회복할 유일한 기회를 소모했다.** 원인이 표본 크기가 아니라 **절차**라는 것이 M1을 나머지 다섯과 구분한다 |
| **부수 효과** | 이 항목이 `open-issues` **9위**(*"외부 판독자 「반드시」 승격이 권고 상태"*)를 **조항으로 승격시킨다** — 그 항목은 어느 사전등록에도 들어가 있지 않았다 |

### C2. 같은 정답지의 회전 수

- [ ] **이 측정이 같은 정답지에 대한 몇 번째 회전인가.** **2회를 넘기지 않는다**
- [ ] 3회째 이상이라면, 산출물을 **성적이 아니라 「적합 과정의 기록」**으로 명시했는가
- [ ] 오염 등급을 **표와 같은 문서 안에** 적었는가 (§3 참조)

| | |
|---|---|
| **미충족 시** | 등급이 한 칸 더 하강한다(post-hoc → post-hoc² → post-hoc³). **등급은 회복되지 않으며**, 회복 경로는 **홀드아웃 개봉과 새 표본**뿐이다 |
| **출처** | **M2** — 증거규칙 v1→v2→v3. 미달할 때마다 *"규칙을 고치면 열릴 것"*이 자연스러웠고, 그 자연스러움이 등급을 단조 하강시켰다 |

### C3. 규칙 설계자와 정답지 열람자의 분리

- [ ] **규칙을 짜는 사람이 오분류 회사명을 알고 있는가**
- [ ] 분리가 불가능하다면, **규칙별 오염 감사를 「설계 후·측정 전」에** 걸었는가
- [ ] 그 감사의 **커버리지 한계**를 함께 적었는가

| | |
|---|---|
| **미충족 시** | 성적을 **인샘플 적합**으로 표기한다 |
| **출처** | **M3** — 레아가 오분류 회사명을 알고 v2를 설계. 인원 제약이라 **감사로 완화했을 뿐 해소되지 않았다** |
| ⚠️ **감사를 과신하지 말 것** | v3 오염 grep은 회사명 **1건 검출**로 보고했으나 인접 주석에 **HCA·Trex·Lazard가 더 있었다** — **과소보고**였다. 판정은 안 바뀌지만(전부 주석, 규칙 조건 아님) **"grep 감사 0건"을 근거로 쓸 수 없다** |

### 🔴 C4. 계측기 → 임계 연결 검사

- [ ] **이 계측기가 산출하는 데이터를, 이 임계가 실제로 소비할 수 있는가**
- [ ] 임계가 요구하는 **셀·분모·비교군이 데이터에 실재하는가** (있을 것이라 가정하지 않았는가)
- [ ] **없으면 어떻게 되는지**가 사전등록에 적혀 있는가 (= **V2 「측정 불성립」에 해당하는 출구**)

| | |
|---|---|
| **미충족 시** | 측정은 **"미달"이 아니라 "잴 것이 없었다"**로 끝나고, 그 자리는 **관측이 아니다** |
| **출처** | **M4** — John 원안이 형식 5요건을 **전부 통과하고도** 무효였다. 그리고 **G1 피해 측정이 실제로 V2로 끝났다** — 49·63·65·67 네 섹터에서 **섹터 자체가 동음이의 업종**이라 비교군 셀이 0개였다 |

### C5. 신설 금지 규율의 저장 위치

- [ ] 이 사전등록·결과 문서에서 **새로 만든 금지 규율이 있는가**
- [ ] 있다면 **이 체크리스트에 항목으로 추가**했는가 (원 문서에만 두지 않았는가)
- [ ] 숫자와 라벨이 **다른 문서·다른 절**에 떨어져 있지 않은가 (**표만 복사하면 라벨이 떨어진다**)

## 5. 이 문서가 말하지 못하는 것

1. **§2가 전수라고 주장하지 않는다.** M1~M6은 **2026-08-03 하루의 산출물에서 그럼발이 찾은 것**이며,
   스파이크 1~6과 crm 저장소 시기의 방법론 부채는 이 목록에 없다.
2. **체크리스트는 검수 도구이지 판정자가 아니다.** 전 항목 통과가 **결과의 타당성을 보증하지 않는다** —
   그것이 정확히 **M4가 가르친 것**이다.
3. **이 문서는 한 번도 적용된 적이 없다.** 다음 사전등록이 첫 사용이며,
   **그때까지 이 문서의 값은 미검증이다.**
