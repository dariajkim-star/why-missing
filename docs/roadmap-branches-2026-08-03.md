# 앞으로의 분기 트리 (John, 2026-08-03)

> **쉬운 말로 한 줄**: 오늘부터 무슨 일이 언제 갈라지는지, 각 갈래에서 daria가 실제로
> 무엇을 하고 언제 끝나는지를 한 장에 그린다. **임계·날짜는 전부 기존 사전등록에서
> 가져온 것이며 이 문서는 새로 정하지 않는다(계약 8).**

## 복명복창

> 기업 공시에서 특정 재무 개념이 경제적으로 존재하는데도 표준 XBRL 금액이 잡히지 않는
> 회사를 찾아서, ①진짜 미공시·누락 ②다른 곳에 적힘 ③애초에 0 을 구분하는 스크리너.
> **최종 질문**: 정상화하면 기업가치·재무비율·투자자 판단이 달라지는가?

## 이 문서의 지위

- **그리기만 한다.** 임계·날짜·판정 규칙의 출처는 전부 아래 넷이다. 하나도 변형하지 않았다.
  - `docs/rescope-interview-preregistration.md` §1·§1-1·§6·§7
  - `docs/g1-damage-measurement-preregistration.md` §6-1 (a)×(b) 귀결표
  - `docs/g1-damage-measurement-results.md` — **(b)는 미달로 이미 입력 완료**
  - `docs/interview-sourcing-adjudication.md` §7 — 판정 (가), 원본 무수정 집행
- **소요·부담 수치는 전부 내 추정**이다. 측정치가 아니며 판정에 쓰지 않는다.
- 이 문서는 문서다. 코드 없음.

## 4. daria의 실제 부담 — **전부 추정. 측정치 아님**

| 가지 | daria가 사람을 만나는 시간 | daria의 문서·손 작업 | 달력 소요 | 합계(추정) |

| **G0 미발송 → T1** | 0 | 마감 4~5h | 1일 | **~5h** |
| **B1 S1 → T1** | 접촉·회신 대응 3~6h (개별 발송, 대량 금지) | 발송 기록표 1h + 마감 4~5h | 8일 | **~10h** |
| **B2/B3 → T1** | 인터뷰 3건 × 30분 = 1.5h + 일정 조율 1.5h + 접촉 3~6h | 기록표 3건 1.5h + 결과 보고 2h + 마감 4~5h | 10일 | **~16h** |
| **B3 통과 → T2** | 위 + 컨시어지 회신 대응 1h | 위 + 손 판정 2~4h + 회신 1h | 12일~ | **~22h** + 무기한 대기 |

**부담의 성격이 가지마다 다르다** — 이것이 시간보다 중요하다:

| 가지 | 부담의 성격 |
|---|---|
| 조달 구간 | **콜드 아웃리치.** 낯선 사람에게 개별 메일. 규칙 확인은 daria 몫이며 규칙 위반은 채널을 닫는다 |
| 인터뷰 구간 | **대본 축자 낭독 + 자기검열.** "좋네요"도 금지, 도구 언급하면 그 인터뷰가 무효(S4). 심리적으로 가장 무거운 구간 |
| 컨시어지 | **손노동.** 자동화 금지가 규칙이므로 시간이 사람 수에 비례 |
| 마감 | **문서 작업만.** 사람 대면 0 |

**가장 무거운 단일 요구는 시간이 아니라 화면 공유 요청이다** — 콜드 접촉 상대에게,
**왜 필요한지 설명할 수단이 금지된 상태로** 업무 화면을 열어 달라고 해야 한다(채널 조사 §4-1).
