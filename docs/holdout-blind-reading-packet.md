## 2. 판독 절차 (스파이크4 사전등록 §2 분류 체계 그대로 — 사후 변경 금지)

개념: `finite_lived_intangibles_net` (유한내용연수 무형자산 순액, ASC 350)

각 회사에 대해 letter 하나를 부여한다:

| letter | 정의 | 정상화 적절성 |
|---|---|---|
| **a** | 실질 부재 / 전액 상각완료 — 유한내용연수 무형자산이 없거나 장부가 0 | ❌ 정당한 부재 |
| **b** | 다른 곳 기재 — 순액이 본문·다른 태그로 공시됨(우리 태그 목록 밖 포함) | ❌ 이중계상 |
| **c** | ASC 350 유한내용연수 무형자산이 아님 — 업종 동음이의(REIT 리스 무형, 보험 DAC/VOBA 등) | ❌ 부적절 |
| **d** | 진짜 누락 — 실재하는데 순액이 어디에도 없음 | ✅ 표적 |

판독 규율:
1. **기계 출력을 보기 전에 5곳 전부의 letter를 먼저 확정·기록**한다(한 곳 판독 → 대조 →
   다음 곳 순서 금지 — 대조가 다음 판독을 오염시킨다).
2. letter마다 **근거 한 줄**을 원문 인용으로 남긴다(예: 스파이크4의
   "no remaining amortizable intangible assets" 방식). 근거 없는 letter는 무효(계약 9의 판독 판).
3. 판정 불가면 억지로 고르지 말고 `undetermined` + 사유(스파이크4에 전례 1건 있음).
4. 기록처: 이 파일 §3 표를 채워 커밋. **커밋 후에** 대조를 시작한다(git 이력이 순서를 증명 —
   스파이크2·3-V 방식).

## 4. 대조 절차 (기록지 커밋 후)

1. `docs/data/evidence-rules-measurement-v3.json`의 `holdout` 절을 연다.
2. letter → 기대 형태 매핑(goldens.py 방식): a → NOT_APPLICABLE/DERIVABLE(=0),
   b → REPORTED_ELSEWHERE, c → INDUSTRY_HOMONYM, d → CANDIDATE_OMISSION.
3. 건별 보고만(n=5, 비율 금지): 기계 1순위 일치 여부, 정답이 표시 목록에 있는지,
   TIE 여부(TIE 일치는 enum 순서의 산물 — 실력 인용 금지, F3 규율 동일).
4. 결과는 `docs/holdout-adjudication-results.md`로 기록하고, **그 결과를 들고 파티 결정**
   — (i) 관측 공간 확장(주석 원문·차원 축, R-16 각성) vs (ii) 재범위.
